# 📕 Volume IV — Retrieval-Augmented Generation

Build reliable systems that combine language models with external knowledge.

## 🎯 Learning Objectives

By the end of this volume you should understand:

1. **Why RAG** - knowledge cutoff, private data, changing data
2. **Document Processing** - PDF, HTML, Markdown, OCR, metadata
3. **Chunking** - fixed, recursive, semantic, overlap
4. **Embedding Models** - dense vectors, cosine similarity
5. **Vector Databases** - pgvector, FAISS, Qdrant, Milvus, Weaviate
6. **BM25** - lexical retrieval, keyword search
7. **Hybrid Search** - RRF, score fusion
8. **Reranking** - bi-encoders vs cross-encoders
9. **Context Compression** - relevance filtering, query-focused extraction
10. **Query Transformation** - rewriting, multi-query, HyDE, decomposition
11. **Advanced RAG** - parent-child, GraphRAG, agentic RAG, corrective RAG
12. **RAG Evaluation** - recall, faithfulness, citation accuracy
13. **Production RAG** - caching, batching, failure handling
