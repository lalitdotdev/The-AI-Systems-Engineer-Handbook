# 📒 Volume V — Agentic AI & Multi-Agent Systems

Move from generating answers to accomplishing goals.

## 🎯 Learning Objectives

By the end of this volume you should understand:

1. **What is an agent?** - Goal, observe, reason, plan, act loop
2. **Agent Architecture** - ReAct, Plan-and-Solve, Tree-of-Thoughts
3. **Tool Calling** - schemas, selection, validation, execution
4. **Agent State** - sessions, checkpoints, persistence
5. **Agent Memory** - short-term, long-term, semantic, episodic
6. **Planning** - task decomposition, replanning, hierarchical
7. **Reflection** - generate, critique, improve
8. **Human-in-the-Loop** - approvals, steering, rejection
9. **Multi-Agent Systems** - supervisor, router, pipeline, debate, peer-to-peer
10. **Multi-Agent Communication** - shared state, message passing, event-driven
11. **Agent Reliability** - loops, tool errors, prompt injection, runaway costs
12. **Agent Evaluation** - task success, tool accuracy, step efficiency, safety
