# 📗 Volume II — Machine Learning & Deep Learning

Understand how models learn and build everything from scratch.

## 🎯 Learning Objectives

By the end of this volume you should understand:

1. **Mathematics foundation** - linear algebra, probability, calculus, optimization
2. **Classical ML** - regression, classification, trees, ensembles
3. **PyTorch** - tensors, autograd, training loops
4. **Neural networks** - MLP, activation functions, backpropagation
5. **Computer vision** - convolutions, CNNs, image classifiers
6. **NLP foundations** - tokenization, embeddings, sequence models
7. **RNNs & LSTMs** - hidden state, vanishing gradients
8. **Attention** - dot-product, multi-head, causal masking
9. **Transformers** - encoder-decoder, positional encoding
