# 📓 Volume VI — Model Context Protocol

Connect AI applications to external systems through standardized interfaces.

## 🎯 Learning Objectives

By the end of this volume you should understand:

1. **MCP Fundamentals** - Host, Client, Server, Tools, Resources, Prompts, Transport, Sessions
2. **MCP Architecture** - How clients, servers, and transports interact
3. **Build an MCP Server** - Calculator, Filesystem, PostgreSQL, GitHub, Slack, Calendar
4. **MCP Security** - Authentication, authorization, least privilege, sandboxing
5. **MCP Production Architecture** - Gateways, routing, monitoring, audit
