# 📘 Volume I — Computer Science & Python

Build the engineering foundation every AI system needs.

## 🎯 Learning Objectives

By the end of this volume you should understand:

1. **Python programming** - variables, data types, control flow, functions
2. **Data structures** - lists, dicts, sets, tuples, trees, graphs
3. **Algorithms** - searching, sorting, dynamic programming
4. **Complexity analysis** - Big-O notation and performance intuition
5. **Async & concurrency** - asyncio, threads, processes
6. **Memory management** - references, garbage collection, leaks
7. **Operating systems** - processes, threads, syscalls, IPC
8. **Networking** - TCP, HTTP, DNS, TLS
9. **Databases** - SQL, transactions, PostgreSQL, Redis
10. **Docker & containers** - images, deployment
